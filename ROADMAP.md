# Roadmap

This roadmap lists the next major improvements for the project.

## Short Term
- improve setup instructions for new contributors
- add clearer backend and frontend documentation
- add backend tests for key API flows
- add frontend validation and empty states
- improve model comparison UI

## Medium Term
- add benchmark and comparison reports
- support more model providers and configs
- improve analytics dashboards and metrics visibility
- add auth and user role support
- improve error handling and logging

## Long Term
- deployment and production docs
- observability dashboards for LLM operations
- cost tracking and performance reporting
- export reports for experiments and evaluations
- advanced prompt and response versioning

## Good First Contributions
- fix typos and improve docs
- write missing unit tests
- improve error messages
- add empty-state UI handling
- improve onboarding steps
